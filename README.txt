龙井视频剪辑 使用说明

一、怎么打开
1. 解压 longjing-video-editing-v0.1-windows.zip
2. 进入解压后的文件夹
3. 双击 LongjingVideoEditing.exe
4. 程序会自动打开浏览器页面

二、怎么生成视频
1. 选择成片风格
2. 点击上传口播，选择口播素材
3. 点击上传环境，选择环境素材
4. 点击添加成片轨道
5. 把素材拖入成片轨道，并调整顺序
6. 点击一键生成
7. 在生成结果里点击单个视频下载，或点击选择文件夹后再一键保存全部

三、文件保存在哪里
上传素材、生成结果、日志都会保存在本软件文件夹内：
- uploads：上传素材
- outputs：生成视频
- downloads：默认保存目录
- logs：运行日志

四、常见问题
1. 双击后没有反应
   打开 logs/startup-error.txt，把里面的内容发给负责人排查。

2. Windows 提示未知发布者
   这是因为当前版本还没有购买代码签名证书。确认来源可信后，可以选择仍要运行。

3. 生成失败
   点击导出日志，把日志文件发给负责人排查。

4. 不要删除 ffmpeg 文件夹
   这是视频生成依赖，删除后会无法生成视频。
